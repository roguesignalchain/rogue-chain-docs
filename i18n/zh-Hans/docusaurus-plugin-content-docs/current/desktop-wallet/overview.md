# 桌面客户端概览

**`rogue-desktop-client`** 是 Rogue Signal 区块链官方图形化钱包、本地节点管理控制器与 CPU 挖矿客户端。它基于 **Tauri v2** 与 **React** 构建，将轻量高效的原生性能与军工级本地密码学安全完美结合。

---

## 🌟 核心特性

* **轻量级原生核心：** 由 Rust 和 Tauri v2 强力驱动，内存占用仅为传统 Electron 钱包的极小一部分。
* **集成式节点管理器：** 直接在图形界面内一键启停本地节点、实时监控区块同步状态并追踪链上日志。
* **内置 RandomX CPU 矿工：** 一键开启本地 CPU 挖矿直接获取 ROGUE，支持自由调节 CPU 线程数并具备实时算力遥测图表。
* **加密金库存储：** 所有私钥与 BIP-39 助记词均在本地磁盘通过 AES-256-GCM 认证加密存储。
* **多账户管理：** 支持从单个 HD 助记词分层推导出多个主权账户并统一管理。

---

## 🖥️ 跨平台支持

官方代码库 Releases 页面提供了各平台的预编译安装包与便携版本：

* **Linux：** `.deb` 安装包与免安装 `.AppImage`
* **Windows：** `.msi` 安装向导与独立便携 `.exe`
* **macOS：** 通用架构 `.dmg` 安装镜像（同时支持 Apple Silicon 与 Intel 处理器）
