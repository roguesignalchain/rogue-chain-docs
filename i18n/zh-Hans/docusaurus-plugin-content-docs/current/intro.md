# Rogue Signal (ROGUE)

**Rogue Signal** 是一条去中心化、采用工作量证明（PoW）机制且完全兼容 EVM 的第一层（Layer 1）区块链，旨在实现抗 ASIC 的极致去中心化。通过在以太坊虚拟机（EVM）执行环境中引入 **RandomX** 工作量证明算法，Rogue Signal 在消费级通用 CPU 上实现了区块验证与挖矿的平民化，同时完整保留了智能合约的可组合性。

## 🛡️ 架构核心支柱

### 1. 全节点 RandomX 实现真正的抗 ASIC 与抗矿场
Rogue Signal 在节点共识层原生集成了经过充分验证的 `RandomX` (`rx/0`) 工作量证明算法。RandomX 在专用虚拟机中执行随机指令序列，每个执行线程需要 2 MiB 的 CPU 三级缓存（L3 Cache）以及 2080 MiB 的 RAM 数据集，彻底杜绝了 ASIC 和 GPU 专用矿机的算力垄断。此外，系统永久禁用了外部 Stratum 代理桥接和 `eth_getWork` RPC 接口：每台挖矿设备都必须运行完整的 `core-rogue` 验证节点。

### 2. 高性能 EVM 可组合性
基于高度优化的 Core-Geth 架构构建，Rogue Signal 提供对以太坊虚拟机（EVM）、Solidity 工具链、Web3 代码库（`ethers.js`、`viem`、`web3.js`）以及现有开发工具（如 Hardhat、Foundry 和 MetaMask）的 100% 原生兼容性。

### 3. 灵敏的难度调节与三层防 51% 攻击安全屏障
突发性全网算力波动（算力激增或云算力租借攻击）由 **LWMA-1** (`N=60`) 难度调整引擎平稳吸收，单区块调整幅度限制在 `+-33%` 之间，并且计算独立于候选区块自身的时间戳。深度区块重组攻击从第 0 号区块起便被 **ECBP-1100 (MESS)** 指数加权评分机制彻底化解。

### 4. 可持续的协议国库
每个新铸造的区块奖励都会在活跃出块矿工（95% / 23.75 ROGUE）与协议国库（5% / 1.25 ROGUE）之间按比例分配，确保为协议后续研发、网络基础设施维护、安全审计及生态发展提供持续的资金支持，杜绝了任何形式的代币预挖（Pre-mine）或 ICO 募资。
