# Rogue Signal 品牌识别

Rogue Signal 代表了一个基于 **RandomX (`rx/0`)** CPU 优先工作量证明共识的主权、高性能去中心化网络。其视觉语言体现了**高对比度战术单色野兽派（High-Contrast Tactical Monochrome Brutalism）**风格——一种植根于密码朋克原则、严谨工程思维与鲜明遥测视觉的美学哲学。

---

## 单色视觉范式

与充斥着浅色渐变和霓虹杂音的泛泛 Web3 设计系统不同，Rogue Signal 严格恪守纯粹黑白的视觉识别体系：

* **虚空深渊 (`#000000` / `#050505`)：** 核心基底。界面架构构建在深邃的黑曜石表面之上，既能实现最大视觉对比度，降低 OLED 显示设备的功耗，又能将注意力聚焦于核心遥测数据。
* **高亮纯白 (`#FFFFFF`)：** 强冲击力的纯白专用于主标题、关键状态指示、密码学哈希以及主操作按钮。
* **战术灰阶 (`zinc-400` 至 `zinc-800`)：** 次级元数据、1px 细发丝分割线、准星十字标和结构性线框占据严格规范的中性灰阶光谱。

## 核心美学溯源

Rogue Signal 视觉系统直接源自官方宣传视觉资产（`promo_*.png`）：

1. **野兽派技术网格：** 干净利落的 1px 正交边框、严谨的几何对齐以及战术方括号标注（`[RX-0]`、`[ID: 800055]`、`[MTP-11]`）。
2. **硬件遥测 HUD：** 遥测风格的数据指标与状态胶囊徽章，灵感来源于高可靠性航空电子仪表盘与主权 UNIX 终端控制台。
3. **纯粹文字排印：** 通过 **Space Grotesk** 呈现极富力量感的几何标题，通过 **JetBrains Mono** 呈现可密码学校验的数据。
